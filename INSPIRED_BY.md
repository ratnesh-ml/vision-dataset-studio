# Inspired by, not copied from

Vision Dataset Studio is a clean-room educational implementation of
data-centric computer-vision quality checks. Its product direction is
informed by [FiftyOne](https://github.com/voxel51/fiftyone), Apache-2.0,
especially its public emphasis on dataset curation, quality, visualization,
and evaluation.

No FiftyOne source code, UI assets, branding, or data were copied. This
repository implements a smaller folder-to-manifest workflow from scratch
and is released under the MIT License.
